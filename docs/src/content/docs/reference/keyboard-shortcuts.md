---
title: Keyboard shortcuts
description: Keyboard shortcuts available in the Easytorier level editor.
---

| Shortcut | Action |
| --- | --- |
| Ctrl+N | Create a new level |
| Ctrl+O | Open a level |
| Ctrl+S | Save the current level |
| Ctrl+Z | Undo |
| Ctrl+Y | Redo |
| Ctrl+D | Duplicate the selected object |
| Delete | Delete the selected object |
| 1–5 | Select, Move, Resize, Scale, or Rotate tool |
| Space + drag | Pan the viewport |
| Middle mouse drag | Pan the viewport |

Shortcut handling can depend on which control has keyboard focus. If a shortcut does not respond, click the viewport or editor first.
