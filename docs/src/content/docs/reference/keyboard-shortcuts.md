---
title: Keyboard shortcuts
description: Object editing, keyframes, selection, and viewport navigation.
---

| Shortcut | Action |
| --- | --- |
| Ctrl+N | New level |
| Ctrl+O | Open XML or legacy JSON |
| Ctrl+S | Save editable XML |
| Ctrl+A | Select all visible objects |
| Ctrl+C / Ctrl+V | Copy / paste selected objects |
| Ctrl+D | Duplicate selection |
| Delete | Delete selection |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Ctrl+Shift+C / Ctrl+Shift+V | Copy / paste the current keyframe |
| 1–5 | Select / Move / Resize / Scale / Rotate |
| Ctrl/Shift-click on canvas | Toggle an object in the selection |
| Ctrl-click / Shift-click in Scene objects | Toggle / select a range |
| Drag empty canvas | Box-select objects |
| Ctrl/Shift + box-select | Add to selection |
| Space+drag / middle-drag / right-drag | Pan |
| Ctrl+wheel | Zoom around pointer |
| Escape | Return to selection or cancel surface drawing |
| Enter during surface drawing | Finish the surface |
| F1 | Show a tip |

Text fields retain normal typing, text undo, and text copy/paste. Click the canvas to focus editor shortcuts. The Pan toggle provides left-drag panning; choosing an editing tool leaves Pan mode.
