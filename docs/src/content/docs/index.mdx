Easytorier is a Windows desktop editor for creating Vector-style parkour levels. Arrange built-in objects and Vector textures, tune the scene in the viewport, animate objects, and compile a level to Vectorier XML.

## What you need

- Windows
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) to build from source

## Need help?

Start with [troubleshooting](/Easytorier/troubleshooting/) or open an issue in the Easytorier repository. Include what you were doing and the exact error text so it can be reproduced.
