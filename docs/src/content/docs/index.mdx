Made by **Zayden Rahman**, Easytorier is a Windows studio for Vector-style parkour levels. Build with prefabs, transform groups, animate objects, add your own music and backgrounds, and keep everything in editable XML.

  <Card title="Build a route" icon="pencil">

  <Card title="Set the atmosphere" icon="sparkles">

    [Custom media](/Easytorier/guides/level-media/)

  <Card title="Plan with Gemini" icon="setting">
