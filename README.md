Easytorier is an upcoming Vectorier tool, planned as a remaster and reimagining of the Vectorier level editor. Its features (all planned, not implemented yet) will be as follows:

# Modern UX
Sleek, black modern UI that makes your experience with Vectorier feel like an artistic showcase.

# AI Features
Has AI built into it, but it does **NOT** do anything major like "Decorate this level for me." Instead, it helps with trigger placement and making dynamic objects for you. Also it can help to make your level flow nicer.

# Tools To Make Level Editing Flow Nicer
Has features like the Dynamic Timeline, Move Visualizer and easy AI path making. (inspired by <@483261487859630080> and <@820289590082535424> 's editors respectively)
